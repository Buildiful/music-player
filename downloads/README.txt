Music Player — standalone offline edition (v1.3.0)

Download and unzip Music-Player-Offline.zip, then open index.html.
Music links to its original files by default. Optional browser-stored copies
can support playback after reopening where browser storage is retained.
The file:// version cannot install a service worker and some browsers cannot
retain original file access between sessions. Google Analytics is disabled
for the file:// edition. The GitHub Pages HTTPS release is recommended for
installing and using Music Player as a progressive web app.
